# Undertale-And-Beyond-Tracker

# Thanks for downloading the Tracker

# To run it you must first launch the start.bat file and install Python and all the dependencies required to run the program
# Once done you need to open any web browser and enter https://localhost:3000/

# You then should launch your game and press the Track button in the menu and the game should send a request to your server which you will need to accept
# Once everything is done you should be able to see your game stats correctly
